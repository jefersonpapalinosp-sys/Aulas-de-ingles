# Pacote de revisão do listening nativo

Três atividades próprias, versão 1, **rascunhos não aprovados para publicação**.
O [guia do piloto](../../docs/listening_nativo.md) apresenta os áudios e o fluxo
de revisão. `activities.json` contém os roteiros, mapa, questões, gabaritos,
explicações, procedência e hashes dos MP3s da pasta `audio/`.

Não altere uma versão já carregada no banco. Correções ou aprovação editorial
exigem nova versão; preserve os arquivos de mídia referenciados por versões
anteriores. Nenhum campo de aprovação foi preenchido automaticamente.
